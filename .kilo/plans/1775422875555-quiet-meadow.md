# Plan: Fix Deployment Error - Missing Exports in airtable.ts

The deployment is failing because `src/app/api/admin/config/route.ts` attempts to import `getConfig` and `updateConfig` from `@/lib/airtable`, but these functions are missing from the file.

## Analysis
- `src/app/api/admin/config/route.ts` needs `getConfig()` and `updateConfig(key, value)`.
- `src/lib/airtable.ts` defines `TABLES.CONFIG = 'Config'`, but lacks the corresponding CRUD functions.
- `src/lib/airtable-types.ts` already has a `ConfigRecord` interface.

## Proposed Changes

### 1. Update `src/lib/airtable.ts`
Add the missing functions to interact with the `Config` table in Airtable.

- **`getConfig()`**: Fetches all configuration records and returns them as an object (key-value pairs) for easier use in the frontend/API.
- **`updateConfig(key: string, value: string)`**: Updates a configuration record by finding it based on the `Key` field.

```typescript
export async function getConfig(): Promise<Record<string, string>> {
  try {
    const records = await base(TABLES.CONFIG).select().all();
    const config: Record<string, string> = {};
    records.forEach(record => {
      const key = record.get('Key') as string;
      const value = record.get('Value') as string;
      if (key) config[key] = value;
    });
    return config;
  } catch (error) {
    return handleAirtableError(error, 'getConfig');
  }
}

export async function updateConfig(key: string, value: string): Promise<ConfigRecord | null> {
  try {
    // Find record by Key
    const records = await base(TABLES.CONFIG).select({
      filterByFormula: `{Key} = '${key}'`,
      maxRecords: 1
    }).firstPage();

    if (records.length === 0) {
      // Optionally create if not exists, or return null. 
      // Given the API usage, we'll try to update existing first.
      const newRecords = await base(TABLES.CONFIG).create([{
        fields: { Key: key, Value: value }
      }]);
      const record = newRecords[0];
      return {
        id: record.id,
        Key: record.get('Key') as string,
        Value: record.get('Value') as string,
        Description: record.get('Description') as string,
      };
    }

    const recordId = records[0].id;
    const updatedRecords = await base(TABLES.CONFIG).update([{
      id: recordId,
      fields: { Value: value }
    }]);

    const updatedRecord = updatedRecords[0];
    return {
      id: updatedRecord.id,
      Key: updatedRecord.get('Key') as string,
      Value: updatedRecord.get('Value') as string,
      Description: updatedRecord.get('Description') as string,
    };
  } catch (error) {
    return handleAirtableError(error, 'updateConfig');
  }
}
```
