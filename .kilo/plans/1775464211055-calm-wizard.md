# Plan: Implement Blacklist Logic for Main Keywords and URL Deletion

This plan addresses two requirements:
1.  Implement double confirmation and data loss warning for URL-level blacklisting.
2.  Prevent blacklisting of a Main Keyword unless the entire URL is blacklisted or a new Main Keyword is assigned.

## Proposed Changes

### 1. `src/features/planning/components/blacklist-reason-modal.tsx`

#### UI and Logic Updates
-   **Update Props**: Extend the `keywords` prop to include `Main_Keyword`.
-   **Validation Logic**:
    -   In `handleSubmit`, if `type === 'Keyword'`, check if any of the selected keywords have `Main_Keyword === 'Y'`.
    -   If a Main Keyword is found, show an error message: "Ein Main Keyword kann nicht einzeln blacklisted werden. Bitte blacklisten Sie entweder die gesamte URL oder vergeben Sie vorher ein neues Main Keyword für diese URL."
-   **Double Confirmation for URLs**:
    -   Add `showUrlWarning` state.
    -   If `type === 'URL'` and `showUrlWarning` is false, set `showUrlWarning(true)`.
    -   Display a destructive alert with the warning about data loss for the URL.
    -   Change the button text to "Endgültig bestätigen".

### 2. `src/features/planning/components/KeywordFilterBar.tsx`

-   Update the `BlacklistReasonModal` invocation to pass the `Main_Keyword` property for each selected keyword.

## Verification Plan

1.  **Test: Blacklist Main Keyword as "Keyword" type**
    *   Select a keyword that is a Main Keyword (`Main_Keyword === 'Y'`).
    *   Open Blacklist modal, select type "Keyword".
    *   Click "Bestätigen".
    *   **Expected**: Error message appears, submission is blocked.

2.  **Test: Blacklist Main Keyword as "URL" type**
    *   Select the same keyword.
    *   Open Blacklist modal, select type "URL".
    *   Click "Bestätigen".
    *   **Expected**: Warning about data loss appears.
    *   Click "Endgültig bestätigen".
    *   **Expected**: Submission succeeds (blacklisting the URL is allowed even if the keyword is a Main Keyword).

3.  **Test: Blacklist Secondary Keyword**
    *   Select a keyword where `Main_Keyword === 'N'`.
    *   Open Blacklist modal, select type "Keyword".
    *   **Expected**: Submission succeeds without extra warning or error.
